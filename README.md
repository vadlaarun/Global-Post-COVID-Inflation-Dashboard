# 🌍 Global Post-COVID Inflation

## 📊 Project Overview

**Global Post-COVID Inflation** is an interactive Power BI dashboard designed to analyze global inflation trends and understand how inflation changed across countries and regions following the COVID-19 pandemic.

The dashboard helps users explore inflation patterns, compare countries, identify major inflationary periods, and understand the economic impact of rising prices in the post-COVID era.

---

## 🎯 Project Purpose

The purpose of this project is to transform global inflation data into meaningful and interactive visual insights.

The dashboard provides a clear view of:

* Global inflation trends before and after COVID-19
* Countries and regions experiencing higher inflation
* Changes in inflation over time
* The impact of inflation on economies and consumers
* Key patterns and trends that can support data-driven analysis

---

## 🛠️ Technologies & Skills Used

* **Power BI**
* **Power Query** – Data cleaning and preprocessing
* **Data Transformation** – Preparing and restructuring raw data for analysis
* **Data Modelling** – Creating relationships and an analytical data model
* **DAX Measures** – Creating calculated measures and KPIs
* **Data Visualization** – Designing interactive charts, graphs, KPIs and dashboards

---

## 📂 Data Source

The dataset used for this project was **imported from Kaggle** and contains global inflation-related data across multiple countries and years.

The raw dataset was cleaned, transformed and modelled in Power BI before being used for visualization and analysis.

---

## 🔍 Project Features & Highlights

### 1. Problem

The COVID-19 pandemic significantly disrupted global economies and supply chains. Following the pandemic, many countries experienced changes in inflation due to factors such as:

* Supply chain disruptions
* Changes in consumer demand
* Rising energy and commodity prices
* Transportation and logistics challenges
* Changes in economic policies
* Geopolitical and global economic factors

With inflation data spread across multiple countries and years, identifying global patterns and comparing inflation trends can be difficult using raw datasets alone.

---

### 2. Impact

The rise in inflation affected both economies and consumers around the world.

Some major impacts include:

* Increased prices of essential goods and services
* Reduced purchasing power of consumers
* Higher household expenses
* Increased cost of production for businesses
* Changes in monetary and economic policies
* Differences in inflation severity across countries

The dashboard provides a visual way to understand these changes and compare inflation patterns across different economies.

---

### 3. Key Insights

The dashboard enables users to identify and analyze insights such as:

* 📈 **Global inflation trends** across different years
* 🌎 **Country-level inflation differences**
* 🔎 Countries experiencing comparatively higher or lower inflation
* 📊 Changes in inflation during the post-COVID period
* 🗓️ Inflation trends across different time periods
* 💡 Major inflationary patterns and fluctuations
* 🌍 Regional differences in inflation performance

These insights help convert a large global dataset into an easier-to-understand analytical story.
